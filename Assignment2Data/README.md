# Required course dataset

Place the four course-provided arrays here:
- `X_train.npy` — 32,000 RGB images, shape (32000, 28, 28, 3), uint8
- `y_train.npy` — 32,000 labels
- `X_test.npy` — 8,000 RGB images, shape (8000, 28, 28, 3), uint8
- `y_test.npy` — 8,000 labels

The large arrays are not included in this repository. This is a course-specific PathMNIST subset/split. Downloading the standard MedMNIST split is not an equivalent reproduction of these saved results. Course participants should obtain the exact arrays from the authorised course source; other readers can inspect the saved notebook outputs without the arrays.

PathMNIST background: https://medmnist.com/ . See notebook references for dataset attribution.
